# ✍️ CodeAlpha insternship Machine Learning — Handwritten Alphabet Recognition

https://github.com/user-attachments/assets/331fbcf0-f0b8-4d30-b695-df20f6cf3bc9



An AI-powered handwritten alphabet recognition system that identifies English capital letters (A–Z) using a Convolutional Neural Network (CNN).

### 🚀 Features
- Draw handwritten letters using an interactive canvas.
- Upload handwritten images for recognition.
- View predicted letters and confidence scores.
- Interactive web interface built with Streamlit.

### 🧠 Technologies Used
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- EMNIST Letters Dataset
- Streamlit

### 🔧 Challenges & Learning
During development, I worked through dataset preprocessing, image orientation, label mapping, model training, and improving predictions on custom handwritten images.

I also learned how to save and reload trained models and deploy a machine learning project as an interactive web application.

### 📁 Project Contents
- Google Colab notebook
- Trained CNN model
- Streamlit application
- Project demonstration video

### 🎯 Objective
To gain practical experience in machine learning, deep learning, image processing, and model deployment.
